# Functions available in SC

Letter | Function |
------ | -------- |
`p`    | Prints out anything after it on the same line. Variable substitution through `p $(x)`. |

# To be added functions

Letter | Function |
------ | -------- |
`q`    | Quits. eg. `q 1` |
`i`    | If statement. eg. `i x > 5` |
`e`    | Ends any statement, such as functions, if statements, for loops, while loops, etc. Think of `}` in C. |
`f`    | For loop. eg `f $i = 0, 100` |
`w`    | While loop. eg `w $i ~ $x` (while `$i` is not equal to `$x`, do this) |
`o`    | Opens a file. eg `o TheHelpingFriendlyBook.txt, b` (Opens the text file with both read and write activated |
